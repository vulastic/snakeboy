# Snakeboy

This repository is a part of the assigments for the ComIT React Course.

---

## Overview

**Snakeboy** is a project that aims to recreate a retro-style Snake game using **HTML**, **CSS**, and **JavaScript**.

The project will be developed in version below:

- Version 1: Build the web page and user interface with HTML and CSS.
- Version 2: Implement the game logic and functionality with JavaScript.
